# Humanitas

Living phylogeny of greatness and truth. Interactive timeline of **110 lives** across about **4,600 years**, with a thesis composed from their principles.

Public site: [https://humanitas.ameriking.io](https://humanitas.ameriking.io)

## What it is
Prophets, mothers of faith, Native nations, Americans, philosophers, and captains. Each life has a biography, principles, creations, and a portrait. Scan a name, open the full page, or generate a thesis.

## Pages
- `/` timeline, search, constellation, thesis
- `/figure/{slug}` single life
- `/classroom` printable discussion pack
- `/embed/{slug}` embeddable card

## Local
Static files. Open `index.html` or any static server from this folder.

Data: `data1.js`–`data6.js`, then `data-enrichment.js` and `data-images.js`. Portraits live in `images/figures/`.
